FILE_01k8s-platform/R&D

              
Multi-Tenant Kubernetes Platform

              
The architecture and Helm charts for moving a forecasting SaaS onto Kubernetes. Each tenant installation gets its own namespace, a single gateway sits at the edge, every module ships as a worker image, and jobs run over Kafka with outbox/inbox and leases.

              
Two charts (platform and installation) wire up Strimzi Kafka, CloudNativePG, KEDA, cert-manager, NetworkPolicy and quotas across four sizing profiles. A PowerShell operator module handles upgrades, rollbacks, restore drills and support bundles, with 288 Pester tests.

FILE_02agent-orchestrator/LOCAL

              
Agentic Dev Pipeline

              
A Product-Owner orchestrator for Claude Code. It breaks work into tasks, runs two developer agents in isolated git worktrees, and sends every branch through a QA agent that must reproduce the build and tests. Green work merges into an integration branch, and a human promotes it to main.

              
Changes are sorted into risk tiers, an adversarial pass tries to refute each review, and any lesson that fires twice becomes a hard gate. I used it to build the 500+ commits of the Kubernetes platform work.

  • Multi-agent
  • Git worktrees
  • QA gates

FILE_03morettamask.exePRIVATE

              
MorettaMask

              
GDPR-compliant document redaction where nothing leaves the machine. PDFs, Office files and scans go through OCR, a regex pass for deterministic identifiers, and a local LLM through Ollama for the hard cases. A person reviews every hit, then the text is irreversibly removed.

              
Files are encrypted at rest with AES-256-GCM, and every action goes into a SHA-256 hash-chained audit log with a verify endpoint. One command starts four containers, with an init container that pulls the model first. It has 160+ green tests across unit, E2E, Playwright and an LLM recall benchmark, run in GitHub Actions.

              
  • .NET 9
  • Blazor
  • Ollama
  • Docker Compose
  • AES-GCM
  • Playwright

FILE_04ibbaic.pyPRIVATE

              
IBBAIC: Activity Forecasting

              
Forecasts PvE, travel and PvP activity in every EVE Online system, hour by hour, from 4 hours to 14 days ahead. A PyTorch model is measured against regression and naive baselines, blended, and given calibrated 80% ranges. A separate classifier estimates who lives in each system.

              
It runs hourly in production with versioned models that can be rolled back, and 1,100+ tests include a check that no future data ever leaks into training rows. Its output feeds a Discord bot and web dashboard built together with a friend.

              
  • Python
  • PyTorch
  • PostgreSQL
  • Docker
  • Forecasting
